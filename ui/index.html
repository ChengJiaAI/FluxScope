                FluxScope — 电控高速示波与静态分析平台
              

              v2.0.0 · MIT
            

            

              面向电机控制（FOC 矢量控制、无感观测器、高速伺服、电调与数字电源）研发调参打造的原生态桌面软件。基于 Rust 与 Tauri 构建，单文件零依赖启动，完整兼容 VOFA+ JustFloat、FireWater、RawData 通信协议，集成多窗口高速实时示波、向量派生公式、14 类可编程右侧仪表控件、六合一后端静态分析台以及 16 接口原生 AI / MCP 双向服务。
            

          


          

            

              交互与功能操作指南
            

            

              

                
1. 示波画布缩放与平移

                

                  
画布内滚轮同时等比缩放 X 时间轴与 Y 幅值轴

                  
坐标轴区滚轮在左轴或底轴刻度区滚动（或按住 Shift），单独缩放单轴

                  
左键按住拖拽上下左右自由平移视口（横向拖拽时自动切为固定时基）

                  
双击 / 自适应全屏复位最佳量程，并自动过滤异常错位飞点

                

              


              

                
2. 时基跟随 · 双游标 · 截图导出

                

                  
时基跟随栏底部开关跟随最新，拖动滑块设定最新帧落点（10%~100%）

                  
双游标 T1/T2拖拽虚线测量时间差与频率，支持选区导出带精确时基的 CSV

                  
右键另存图片画布右键另存图像时，自动包含窗口标题与全部变量颜色图例

                  
全局快捷键Space 暂停或继续采集回放，Tab 收起或展开右侧仪表栏

                

              


              

                
3. 六合一后端静态分析台（分析页）

                

                  
实验数据集池即开即载当前缓冲快照，支持抓选区、抓全缓冲与外部 CSV 归档

                  
多维叠图对齐支持自动归零、差值曲线解算，以及按住 Shift+左键拖曲线微调

                  
阶跃与频谱多轮阶跃上升/超调/调节时间对比，加窗 FFT/THD 与谐波诊断

                  
离线滤波沙盒实时对比 5 类滤波器纹波衰减与群延迟，一键生成下位机 C 代码

                

              


              

                
4. 显示增益 · 仪表控件 · AI 联调

                

                  
独立显示增益通道页可设绘波乘数，仅缩放曲线高度，不影响任何读数与导出

                  
向量派生公式支持四则运算、三角函数、低通滤波、滑动平均与微分实时解算

                  
多优先级控件14 类侧栏仪表支持上下拖拽排序，可设多条优先级条件超限变色

                  
原生 MCP 服务终端页复制指令发给主流 AI 客户端，即可双向读写配置与波形
